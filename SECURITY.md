# Security

| Area | Details |
| --- | --- |
| Privileges | Administrator |
| RustDesk validation | Tested build hash, or official signature and pinned publisher key |
| Certificate validation | Local certificate cache |
| Control pipe | Local machine, current user and session |
| Data | `%ProgramData%\RustdeskTUNHelper\<user SID>` |
| Logs | Processes, adapters, destination IPs and errors |
| Drivers, injection, autostart, auto-update, telemetry | None |
| Code signing | Unsigned |

Include the version, reproduction steps and redacted logs when reporting an issue. Remove passwords, tokens and remote IDs.
